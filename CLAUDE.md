Custom Shopify theme based on Dawn (v15.4.0) for an e-commerce fashion store. Built with Liquid templating, vanilla JavaScript Web Components, and CSS custom properties.

## Core Architecture

### Directory Structure

- `sections/` - Reusable page sections with `{% schema %}` definitions (e.g., `hero-carousel.liquid`)
- `snippets/` - Reusable components rendered via `{% render %}` (e.g., `card-product.liquid`, `price.liquid`)
- `templates/` - JSON page templates composing sections (e.g., `index.json`, `product.json`)
- `layout/` - Base layouts (`theme.liquid` for standard pages, `password.liquid` for password-protected stores)
- `assets/` - JavaScript, CSS, and static files
- `config/` - Theme settings (`settings_schema.json`, `settings_data.json` - **MUST be tracked in git**)
- `locales/` - Translation files

### Sections vs Snippets

**Sections** are standalone, configurable page blocks with `{% schema %}` JSON definitions at the end. They power the Shopify theme editor and can be added/removed via JSON templates or the admin interface.

**Snippets** are reusable components without schemas, rendered with `{% render 'snippet-name', param: value %}`. They cannot include sections, but sections can include snippets.

### Template Composition

JSON templates in `templates/` compose sections:

```json
{
  "sections": {
    "image_banner": {"type": "image-banner", "settings": {...}},
    "featured_collection": {"type": "featured-collection", "settings": {...}}
  },
  "order": ["image_banner", "featured_collection"]
}
```

**⚠️ CRITICAL: 62.5% Font-Size Trick & Typography**

This theme uses the "62.5% font-size trick" on the `<html>` element (common in Dawn themes), making `1rem = 10px` instead of `16px`. This **breaks all rem-based Tailwind classes**:

| Tailwind Class | Expected Size | Actual Size (with 62.5%) |
|----------------|---------------|--------------------------|
| `text-sm` (0.875rem) | 14px | 8.75px ❌ |
| `text-base` (1rem) | 16px | 10px ❌ |
| `text-lg` (1.125rem) | 18px | 11.25px ❌ |

**Why container resets don't work:** Setting `font-size: 16px` on a container element does NOT fix this. The `rem` unit is **always** calculated from the root `<html>` element, not parent containers.

**Solution:** Always use Tailwind's **arbitrary value syntax with pixels**:

```html
<!-- ❌ WRONG - will render too small -->
<p class="text-sm md:text-base">This text will be tiny</p>

<!-- ✅ CORRECT - use pixel values -->
<p class="text-[14px] md:text-[16px]">This text renders correctly</p>
```

**Typography Scale for Account Pages:**
| Purpose | Mobile | Desktop | Classes |
|---------|--------|---------|---------|
| Section titles | 16px | 18px | `text-[16px] md:text-[18px]` |
| Card titles | 15px | 16px | `text-[15px] md:text-[16px]` |
| Body text | 14px | 15px | `text-[14px] md:text-[15px]` |
| Secondary text | 13px | 14px | `text-[13px] md:text-[14px]` |
| Labels/counts | 12px | 13px | `text-[12px] md:text-[13px]` |

  src="{{ image | image_url: width: 533 }}"

## Modular Collection System

The theme includes a **modular collection system** built with Tailwind CSS that can be used across any page type (collection pages, homepage, custom pages). This system consists of 3 independent sections and 1 product card snippet.

### Architecture

#### 1. Collection Grid Section (`sections/collection-grid.liquid`)
**Purpose:** Reusable product grid that displays products from any collection.

**Features:**
- Collection picker in theme editor (or uses current collection on collection pages)
- Configurable columns (mobile & desktop)
- Pagination support (enable/disable)
- "View All" button option (when pagination disabled)
- Product metafield support (3 optional lines)
- Built with Tailwind CSS

**Usage Examples:**
- Add to homepage to feature a collection
- Add to collection pages for custom grid layout
- Add to custom pages to showcase products

**Theme Editor Settings:**
- Collection selection
- Show/hide collection title & description
- Products to show (2-50)
- Columns: mobile (1-3), desktop (2-6)
- Enable pagination toggle
- Product metafield configuration (namespace.key format)

#### 2. Collection Top Bar Section (`sections/collection-top-bar.liquid`)
**Purpose:** Sticky header with navigation, search, cart, and functional filter chips.

**Features:**
- Sticky positioning (top of page)
- Back button (uses browser history)
- Collection title (custom or automatic)
- Search and cart icons
- **Functional filter chips** - Click to filter products via Shopify's facets system
- Horizontal scrolling chip bar
- Block-based chip configuration (no metafields required)

**Filter Chips Functionality:**
- Chips update URL parameters (e.g., `?filter.p.tag=men`)
- Server-side filtering via Dawn's facets system
- Active state shows currently applied filters
- "All" chip clears all filters
- Supports: Product tags, Product type filters

**Theme Editor Settings:**
- Custom title override
- Show/hide back button, search, cart icons
- Add chip blocks with:
  - Label (e.g., "Men", "Women", "Sale")
  - Filter type (tag, product_type, vendor)
  - Filter value (empty for "All" chip)

**Preset Configuration:**
Default preset includes "All", "Men", "Women" chips.

#### 3. Collection Sort & Filter Bar Section (`sections/collection-sort-filter-bar.liquid`)
**Purpose:** Sticky bottom bar with SORT and FILTER buttons.

**Features:**
- Sticky positioning (bottom of viewport)
- SORT button opens custom bottom sheet drawer
- FILTER button opens custom bottom sheet drawer
- Sort options from collection.sort_options
- Active sort indicator
- Smooth animations (slide-up drawer)
- Supports size, color, price range, and other product variant filters

**Theme Editor Settings:**
- Optional collection handle (or uses current collection)

**Behavior:**
- SORT: Opens custom drawer with sort options, updates URL with `?sort_by=...`
- FILTER: Opens custom drawer with filter options (size, color, price, tags, product type)
- Shows empty state with setup instructions when no filters are configured

**Filter Configuration Required:**
Filters must be enabled in Shopify Admin → Search & Discovery:
- Variant options (Size, Color, Material, etc.)
- Price range filter
- Product type
- Product tags
- See "Setting Up Filters" section below for detailed instructions

#### 4. Modern Product Card Snippet (`snippets/collection-product-card-modern.liquid`)
**Purpose:** Myntra-style product card used across all collection grids.

**Features:**
- Hover effect on image (scale transform)
- Single-line title with ellipsis
- **Myntra-style pricing:**
  - Line 1: Sale price (bold, green)
  - Line 2: Compare-at price (strikethrough) + discount % pill (orange)
- 3 optional metafield lines (configurable)
- Responsive images with lazy loading
- Built with Tailwind CSS

**Styling:**
- Green sale price: `text-green-600`
- Orange discount pill: `bg-orange-100 text-orange-700`
- Gray text for metafields
- Rounded corners, shadow on hover

### Color Swatch System

The theme uses a centralized color swatch snippet that looks up colors from Shopify's standard Color metaobjects.

#### Color Swatch Snippet (`snippets/color-swatch-hex.liquid`)

**Purpose:** Returns hex color code for a given color label.

**How it works:**
1. Looks up the color from `shop.metaobjects['shopify--color-pattern'].values`
2. Matches by label (case-insensitive)
3. Returns `color_obj.color` (the hex value)
4. Falls back to a conic gradient for "multicolor"

**Usage:**
```liquid
{%- capture swatch_color -%}{%- render 'color-swatch-hex', color_label: value.label -%}{%- endcapture -%}
<div style="background: {{ swatch_color }};"></div>
```

**Important:** The metaobject field is accessed with lowercase `color_obj.color`, NOT `color_obj.Color`.

The filter system has different implementations for mobile and desktop:

#### Mobile Filter Drawers
- Files: `snippets/search-sort-filter-bar.liquid`, `sections/collection-sort-filter-bar.liquid`
- Full-screen drawer with left sidebar navigation
- Color swatches: 5-column grid, NO selected state (clean look)

#### Desktop Filter Sidebars
- Files: `sections/search-landing.liquid`, `sections/collection-grid.liquid`
- Sticky sidebar (280px width)
- Color swatches: 5-column grid, NO selected state (clean look)
- Text size: 11px for color labels with ellipsis truncation

#### Color Swatch Grid Styling
```css
/* 5-column fixed grid */
display: grid;
grid-template-columns: repeat(5, 1fr);
gap: 0.8rem 0.4rem;

/* Text truncation for long labels like "Multicolor" */
max-width: 100%;
overflow: hidden;
text-overflow: ellipsis;
white-space: nowrap;
```

#### Browser History Behavior
- First filter change uses `pushState` (creates history entry)
- Subsequent filter changes use `replaceState` (no new entry)
- Browser back button clears ALL filters at once
- Managed via `hasFilterHistoryEntry` flag in `collection-filter-ui.js`

### Setting Up Filters

The filter drawer displays filters configured in your Shopify Admin. Follow these steps to enable filters:

#### Step 1: Enable Search & Discovery

1. Go to **Shopify Admin** → **Settings** → **Apps and sales channels**
2. Click **Develop apps** or search for **Search & Discovery** app
3. Install and enable the **Search & Discovery** app (free, built by Shopify)

#### Step 2: Configure Product Filters

1. Go to **Shopify Admin** → **Online Store** → **Filters** (or search for "Search & Discovery")
2. Click **Customize filters**
3. Enable the following filters:

**Recommended Filters for Fashion/E-commerce:**
- ✅ **Size** - Variant option filter (shows all size options: S, M, L, XL, etc.)
- ✅ **Color** - Variant option filter (shows all color options)
- ✅ **Price** - Price range filter with min/max inputs
- ✅ **Product type** - Filters by product category (T-Shirt, Jeans, Shoes, etc.)
- ✅ **Tags** - Filters by product tags (Sale, New Arrival, Trending, etc.)
- ⚪ Material - Variant option filter (optional)
- ⚪ Style - Variant option filter (optional)

#### Step 3: Set Up Product Variants

For **Size** and **Color** filters to work, your products must have variants with these options:

1. Go to **Products** → select a product
2. In the **Variants** section, ensure you have options like:
   - Option 1: **Size** (values: S, M, L, XL)
   - Option 2: **Color** (values: Black, White, Blue, Red)
3. Save the product

**Example Product Setup:**
```
Product: "Cotton T-Shirt"
Variants:
- Size: S, Color: Black
- Size: M, Color: Black
- Size: L, Color: White
- Size: XL, Color: White
```

#### Step 4: Add Product Tags (for tag filtering)

1. Go to **Products** → select products
2. In the **Organization** section, add tags like:
   - `sale` - For discounted products
   - `new` - For new arrivals
   - `trending` - For popular items
   - `men` - For men's products
   - `women` - For women's products
3. Save products

#### Step 5: Set Product Types

1. Go to **Products** → select a product
2. In the **Organization** section, set **Product type**:
   - Examples: `T-Shirt`, `Jeans`, `Shoes`, `Jacket`, `Dress`
3. Save the product

#### Step 6: Test Filters

1. Go to your collection page
2. Click the **FILTER** button in the bottom bar
3. You should now see filters like:
   - **Size** (with checkboxes: S, M, L, XL)
   - **Color** (with checkboxes: Black, White, Blue, Red)
   - **Price** (with min/max inputs)
   - **Product type** (T-Shirt, Jeans, etc.)
   - **Tags** (Sale, New, Trending)

#### Troubleshooting

**No filters showing?**
- Ensure Search & Discovery app is installed and filters are enabled
- Check that products have variants with Size/Color options
- Verify products have tags and product types set
- Collections must have products with the configured filter attributes

**Filters not updating products?**
- Clear browser cache
- Re-save the collection in Shopify admin
- Check URL parameters are being added correctly (e.g., `?filter.v.option.size=M`)

**Empty state showing in filter drawer?**
- This means `target_collection.filters` is empty
- Follow steps above to configure filters in Search & Discovery

## Shopify Metafields Reference

### Standard Category Metafields

Shopify's standard category metafields (set via Product → Category in admin) use the **`shopify`** namespace, NOT `category`.

**Common metafield keys:**
| Admin Label | Liquid Key | Type |
|-------------|------------|------|
| Color | `shopify["color-pattern"]` | `list.metaobject_reference` |
| Material/Fabric | `shopify.fabric` | `list.metaobject_reference` |
| Target Gender | `shopify["target-gender"]` | `list.metaobject_reference` |
| Neckline | `shopify.neckline` | `list.metaobject_reference` |
| Sleeve Length | `shopify["sleeve-length-type"]` | `list.metaobject_reference` |
| Size | `shopify.size` | `list.single_line_text_field` |

**Important:** Keys with hyphens require bracket notation: `product.metafields.shopify["color-pattern"]`

### Accessing Color Metafield Values

The color metafield is a `list.metaobject_reference` containing objects with `color` (hex) and `label` (name).

**WRONG - `.first` doesn't work on metaobject references:**
```liquid
{% assign color_data = product.metafields.shopify["color-pattern"].value.first %}
{{ color_data.color }}  {# Returns blank #}
```

**CORRECT - Use a for loop:**
```liquid
{%- assign color_hex = "" -%}
{%- assign color_label = "" -%}
{%- for item in product.metafields.shopify["color-pattern"].value -%}
  {%- if forloop.first -%}
    {%- assign color_hex = item.color -%}
    {%- assign color_label = item.label -%}
  {%- endif -%}
{%- endfor -%}

<span style="background: {{ color_hex }};">{{ color_label }}</span>
```

### Custom Metafields

Custom metafields use the `custom` namespace:
```liquid
{{ product.metafields.custom.related_colors.value }}  {# List of Products #}
{{ product.metafields.custom.badge_text.value }}      {# Single text #}
```
